# ADR-0005: quota 缓存与超时 fallback

## 日期
2026-06-22

## 状态
已采纳

## 背景
前端每 5 分钟刷新全部 provider 额度，直接调上游 API 可能超时（智谱/DeepSeek 偶发慢）。如果超时直接报错，前端显示空白或错误，用户体验差。

## 决策
60 秒 TTL 缓存 + 超时 fallback 到旧缓存（即使过期也比报错好）。

## 规则细节

| 参数 | 值 |
|------|-----|
| 缓存 TTL | 60 秒 |
| 上游 API 超时 | 10 秒 |
| 超时后行为 | 返回旧缓存数据并标记 `cached: true` |
| 无旧缓存 | 返回 504 |

## 决策人
基围虾（CTO）

## 备注
- 设计哲学：额度数据不是实时关键信息，宁可显示"1分钟前的旧数据"也不显示"加载失败"
- 前端可根据 `cached: true` 标记给用户提示"数据可能不是最新"
