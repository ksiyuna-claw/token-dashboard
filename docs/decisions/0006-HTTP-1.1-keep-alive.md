# ADR-0006: HTTP/1.1 keep-alive

## 日期
2026-08-10

## 状态
已采纳

## 背景
看板默认用 Python `http.server` 的 HTTP/1.0，cloudflared 隧道用 HTTP/1.1 有 keep-alive。连接复用时，cloudflared 复用了一个已被服务端关闭的 socket，导致 `connection reset by peer`，前端显示"请求失败"。

## 决策
handler 类显式设置 `protocol_version = "HTTP/1.1"`，使服务端支持 keep-alive，与 cloudflared 行为一致。

## 规则细节
```python
class DashboardHandler(http.server.BaseHTTPRequestHandler):
    protocol_version = "HTTP/1.1"
```
